# Slack DM Page UI Clone

A static UI clone of Slack's Direct Messages (DM) page built using
**HTML5** and **CSS3**.

This project focuses on replicating the layout and visual structure of
Slack's DM interface using semantic HTML and modern CSS techniques such
as Flexbox and positioning.

------------------------------------------------------------------------

## 📌 Project Overview

This project includes:

-   Sidebar layout
-   Direct message list
-   Chat conversation section
-   Message bubbles
-   Profile section
-   Basic responsive behavior

It is built purely for UI practice and frontend fundamentals.

------------------------------------------------------------------------

## 🛠️ Tech Stack

-   HTML5
-   CSS3
-   Flexbox
-   Semantic Markup
